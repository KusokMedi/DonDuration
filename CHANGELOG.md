# Changelog

## [1.2.1] - 2026-07-07

### 🐛 Исправления (Bugfix)
- **Критическое исправление загрузки плагина**: Изменен `depend` на `softdepend` для PlaceholderAPI в `plugin.yml`
  - **Проблема**: Плагин не мог загрузиться на серверах без PlaceholderAPI, выдавая ошибку `UnknownDependencyException`
  - **Решение**: PlaceholderAPI теперь является мягкой зависимостью, что позволяет плагину загружаться и корректно сообщать об отсутствии зависимостей через встроенную проверку
  - Плагин по-прежнему требует PlaceholderAPI для работы, но теперь корректно обрабатывает его отсутствие

### 📝 Технические изменения
- Обновлена версия с `1.2` до `1.2.1`
- PlaceholderAPI перемещен из `depend` в `softdepend` в plugin.yml
- Обновлена документация (README.md) с информацией о новой версии

### ⚠️ Важно
Плагин по-прежнему **требует установки PlaceholderAPI** для корректной работы. Изменение только позволяет плагину загружаться и выводить понятное сообщение об ошибке, если зависимость отсутствует.
