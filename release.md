# DonateDuration v1.2

- ⚡ **Система кэширования** - значительное снижение нагрузки
- 🐛 **Debug режим** - детальное логирование для отладки
- 📈 **bStats метрики** - статистика использования плагина
- ✅ **Проверка зависимостей** - автоматическая проверка LuckPerms/PlaceholderAPI
- 🔧 **Улучшения кода** - исправлены hardcoded версии

**Требования:** Spigot/Paper 1.16.5 - 1.26.2 · Java 21+ · PlaceholderAPI · LuckPerms
